# Handleliste

Enkel handleliste-app for mobil. Ingen innlogging – lista lagres på telefonen og virker uten nett.

**Åpne appen:** https://krissalt.github.io/Handleliste/

Legg den på hjemskjermen: åpne lenken på mobilen → Del/meny → «Legg til på Hjem-skjerm».

## Funksjoner
- Skriv antall rett inn: «2 melk», «kjøttdeig 400 g»
- Autofyll fra en innebygd vareliste med ca. 600 vanlige dagligvarer
- Varer sorteres automatisk i 15 kategorier etter en typisk butikkrunde
- Flere varer legges til i `products.js`
- Trykk på ringen for å krysse av, fjern alle avkryssede med én knapp
- Trykk på navnet for − / + på antall
- Varer som havner i «Annet» samles under «Sorter» – velg kategori én gang, så huskes den
- Hurtigknapper for varer du har kjøpt før
- Angre sletting, mørk modus, virker offline
