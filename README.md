# Handleliste

Enkel handleliste-app for mobil. Ingen innlogging – lista lagres på telefonen og virker uten nett.

**Åpne appen:** https://krissalt.github.io/Handleliste/

Legg den på hjemskjermen: åpne lenken på mobilen → Del/meny → «Legg til på Hjem-skjerm».

## Funksjoner
- Skriv antall rett inn: «2 melk», «kjøttdeig 400 g»
- Varer sorteres automatisk etter kategori
- Trykk for å krysse av, fjern alle avkryssede med én knapp
- Hurtigknapper for varer du har kjøpt før
- Angre sletting, mørk modus, virker offline
